# Weather App | Live City Weather

Weather app that fetches live weather for any city using a public API, built with HTML, CSS and JavaScript.

**Live demo:** https://soni200294.github.io/weather-app-web/

## Features
- Search any city and see temperature, conditions, humidity and wind speed
- Live data from the Open-Meteo API
- Recent searches saved in the browser
- Error handling for unknown cities and network problems

## Tech Used
HTML, CSS, JavaScript (fetch API, async/await)

## How to Run
Open the live demo link, or download the repo and open `index.html` in a browser.
